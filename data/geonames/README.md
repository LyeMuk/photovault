# data/geonames/

Offline geocoder dataset (GeoNames `cities500` + admin1 + country info, docs/CONTEXT.md
§4.1/§9) compiled into a compact binary by a build script (`scripts/build-geocoder`,
added when Phase 3 — Location — starts). Raw source data is fetched, not committed.
